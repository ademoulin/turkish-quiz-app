# Decisions made for version one

These are minor implementation defaults, recorded so they can be changed after using the app.

- Accept either Turkish entry when its accepted English meanings overlap with the prompt's entry (for example, demek/söylemek for “say”). This is intentionally lenient; no fuzzy spelling matching or guessed external synonyms. The displayed English definition can contain more detail than the overlapping meaning.
- Treat `de / da` as two accepted Turkish variants. Do not split slash characters in English definitions automatically: “get off/out of” needs a deliberate override rather than treating “out of” as a complete meaning.
- Explicit Acceptable English overrides use only the pipe separator. Otherwise split commas/semicolons outside parentheses, and accept forms with parenthetical words included or omitted. Ignore leading “to” for verb meanings.
- Keep Turkish letter distinctions using Turkish-aware lowercase and Unicode normalization; ignore surrounding common sentence punctuation and repeated whitespace. Extra subject pronouns are not required or accepted in a conjugation answer: the field asks for the conjugated verb.
- Keep combined word-type codes and include them under matching simple-type filters. vt/i is a verb. Case information remains separate metadata for future exercises.
- A fixed-length session is capped at the selected entry count, with one question per entry. Each new conjugation session chooses fresh random forms; this avoids unexpectedly repeating vocabulary within a session.
- Retain hidden selections when filtering. “Select all matching” adds visible matches; “Clear matching” removes only visible matches.
- Ability + conditional combinations are deferred. If selected with other tenses, conditionals use ordinary forms and show no Ability badge. If ability-only settings select exclusively conditionals, explain the conflict before starting.
- The pattern English cue always uses “come”, labeled as an example. This avoids unreliable automatic English conjugation or translation of dictionary explanations.
- With an explicit onlar, accept the standard plural and singular-form predicates. For past continuous accept geliyorlardı, geliyordular, and geliyordu; for open conditionals accept gelirseler, gelirlerse, and gelirse.
- A manual correction changes the existing attempt's correctness and is counted once in both progress and the score. Its manual marker remains visible.
- Review mistakes by entry ID, direction, and grammatical combination. A later correct result resolves that combination; other difficult forms stay in the review pool.
- Preserve progress for deleted sheet IDs. Do not silently transfer it to a new ID. Imported attempts with matching attempt IDs replace those same attempts; other existing results remain.
- The source was uploaded to GitHub on your explicit instruction. GitHub Pages hosting was subsequently authorized. The gh-pages branch contains the compiled public site; GitHub repository Pages settings control publication. No analytics, paid services, or app accounts have been introduced.

- The word-type menu groups vt, vi, and vt/i under Verbs. Previously saved verb-type filters now show all verbs; sheet metadata stays unchanged.

- Interface and project documentation use American English, as requested; the user’s current location does not determine spelling preferences.

- Vocabulary familiarity uses four labels and a multi-select filter, with separate histories by direction. Mixed uses the weaker direction; conjugation does not contribute. Existing history contributes through conservative 30-minute-gap session estimates.
- Familiar requires 4 successful sessions over 2 days; Well known requires 12 over 3 days. Recent session evidence controls confidence and can demote a word after repeated misses. Repeated guesses in one session do not create extra positive evidence; manual corrections update original evidence. No time decay or automatic prioritization is introduced.
- Familiarity filters restrict the selected entries eligible for a new session, even if other entries were selected earlier. Hidden selections remain saved. Review mistakes intentionally retains its existing separate behavior.

- Answer grading treats a and â as equivalent in both languages and all quiz modes. Display spelling stays unchanged; other Turkish letter distinctions remain significant.

- Conjugation grading alone treats g/ğ, i/ı, c/ç, s/ş, o/ö, and u/ü as equivalent. Vocabulary retains Turkish letter distinctions (apart from the previously approved a/â equivalence). Correct conjugations and explanations keep their proper Turkish spelling.

- Typed case pilot: 10 newly authored draft form-completion questions each for locative, dative, and ablative. The requested case is explicit; this is form production, not evidence of choosing cases or producing sentences. Yeni Hitit 1 §2.2 (printed p.29) guides scope; these are not textbook quotations. Independent linguistic review remains pending.
- Ödkem Rules mapping from the provided workbook snapshot: dative 14, locative 15, ablative 16. Supporting rules are major vowel harmony 2, consonant mutation 4, consonant assimilation 5, and buffer consonants 8. Supporting rules do not receive separate success/mastery credit. Mapping is maintained in `catalogMapping`; future catalog edits must be reconciled deliberately.
- Typed grammar grading uses NFC, edge whitespace trimming, and Turkish-aware case folding only. It preserves Turkish letter distinctions and does not reuse conjugation tolerance. Pilot words avoid proper-name apostrophes and incidental punctuation.
- Pilot evidence lives in optional `pilotAttempts` inside the existing browser store and version 1 backup envelope. Older backups omit it and import without erasing pilot history. Matching attempt IDs replace the same result; manual correction changes the original attempt. Pilot history is separate from vocabulary familiarity and mistake review. No grammar mastery thresholds or labels are assigned.

- Mixed typed-case sessions select four questions per case (12 total), then shuffle the combined pool. Every question continues to name the required case: this is still form production. Single-case sessions retain all 10 questions.
- Grammar mistake review uses the latest timestamped evidence per question ID, after deduplicating attempt IDs. Ties use later history order. A later correct answer or manual correction clears that question; a later miss reopens it. Review respects the selected case or includes all cases with Mixed. Unknown question IDs remain saved but are not playable. Review sessions snapshot the eligible pool so corrections do not move the current question. This is a review queue, not a mastery classification.
- Optional `practiceMode` metadata distinguishes single-case, mixed-case, and mistake-review attempts. Old backups without it remain valid. Every review session saves fresh evidence; manual correction still updates that session's original attempt.

- Expanded typed form completion to 50 newly authored draft questions: 10 each for five cases. Accusative maps to Ödkem 35 and Yeni Hitit 1 §6.1, printed p.73. This batch does not test construction choice, plural phrases, case stacking, or whole sentences. Independent linguistic review is pending.
- Phrase answers use the separate typed_noun_phrase exercise type and genitive_possessive_phrase concept. Record both base nouns and number constraints in the original attempt. Earlier genitive-only and possessive-only results do not count as whole-phrase evidence. All practice families keep separate pools and mistake queues; the interaction component is shared.
- Phrase grading normalizes NFC, Turkish-aware case and edge/repeated internal whitespace only. Word order, both sets of endings and Turkish spelling remain significant; punctuation and extra words are not stripped. Word-form and other quiz grading policies are unchanged.
- Version-1 backups continue to support old word-form histories; new phrase evidence requires its new exercise type and explicit noun/number context. Corrections update the original attempt; successful later phrase attempts clear the phrase review queue. No grammar mastery labels or thresholds are added.

- Grammar practice shows one activity at a time through a labeled activity chooser. Cases are the default; possessives, whole noun phrases, and Yeni Hitit multiple choice are selectable. Switching keeps each in-progress session and answer mounted while practice remains open; closing practice still resets sessions as before. Grading, banks and saved evidence are unchanged.
