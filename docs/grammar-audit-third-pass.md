# Grammar audit: relatives and introductory converbs

## What changed

Lessons 9–10 keep three useful task views, but their choices now target different decisions:

- Meaning: interpret the described event, with the actor held constant in alternatives. Wanted/needed actions and a different temporal context replace impossible readers such as a book reading a student.
- Structure: choose a modifier appropriate before a head noun, distinguish relative agreement from a whole content-clause case ending, bracket the relative description, or read contextual time. Form-choice examples include `okuduğum / okuduğumu / okumam`; the completed modifier is blanked out. Other options are short analyses rather than a correct mini-lecture beside two short distractors.
- Typed production: unchanged explicit participle targets and strict spelling.

Introductory converb lessons 11A–C now have two scored tracks:

- Meaning: alternatives preserve the actor and core vocabulary. For -Ip, distinguish the stated sequence from reversal or leaving an action undone. For -ArAk, distinguish means/manner from omission or a separately ordered action. For -mAdAn, distinguish the omitted action from reversed scope or doing it before the main action. Do not infer that a scoped omission means never doing the action later.
- Typed production: unchanged named converb forms. Shared subject, tense/person source, harmony and buffers remain explained in the unscored guide and feedback instead of a repetitive third track.

Six meaning and six typed questions appear in a mixed introductory-converb session, without repeating a model. Later time-converb lessons retain their separate structure tasks because event order, overlap and differing actors add useful decisions.

## Evidence and preservation

The 60 revised meaning questions and 24 revised relative structure questions get new IDs. Their old versions and the 36 removed converb structure questions remain recognizable as earlier-version evidence; they stay in history/exports and outside current review/statistics. Current lesson total: 860 tasks across the same 312 models. All 60 affected typed targets, all assembly answers and unrelated question objects are unchanged. No original MC bank, noun/case practice, finite-conjugation, storage schema or routing changes.

The original models and their source mappings remain unchanged: Yeni Hitit 2 §8.1 p.91 / §8.2 p.95 for relatives; Yeni Hitit 1 §11.1 p.133 / §11.2 p.137 and support p.171 for these converb patterns. New alternatives are app-authored drafts, not textbook questions. This is an exercise-design review, not independent linguistic approval. Exact Ödkem mapping remains pending.
